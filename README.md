# TextRPG
Project for the course "Advanced Programming in C/C++"

The aim of this project is to develop a text-based role-playing game (RPG) in C++. The player moves through a dungeon, fights monsters, collects treasures and tries to reach the exit. The game will run mostly in the terminal, with GUI and dungeon map elements planned as optional extensions if time permits.

Key features:
Turn-based battles
Level system and character building
Items and treasure chests
Simple GUI (optional)
Save function (optional)

Build with:
make

run with: 
.\dungeon_rpg.exe
